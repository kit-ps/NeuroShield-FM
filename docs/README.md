# NeuroShield project website

This directory contains the static project website published at
<https://kit-ps.github.io/NeuroShield-FM/>.

The website was developed by Lynn Keil for the NeuroShield project and was
migrated from <https://github.com/lynn3543/neuroshield>. Its footer preserves
the upstream template acknowledgements and Creative Commons
Attribution-ShareAlike 4.0 license notice.

GitHub Pages should be configured to publish from the `docs/` directory on the
`main` branch.
